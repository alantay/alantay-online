# Personal Site

Alan Tay's personal site at alantay.online: introduces him, shows his work, and presents his resume, mainly to recruiters.

## Language

**Visitor**:
Anyone viewing the site; the primary one is a recruiter or hiring manager evaluating Alan.
_Avoid_: User, audience

**Project**:
A piece of Alan's work that can be publicly shown, with a live link and/or visuals.
_Avoid_: Work, portfolio item

**Case Study**:
A Project's dedicated page explaining the problem, Alan's role, key decisions, and outcome.
_Avoid_: Project page, write-up

**Experience**:
A past employment role (employer, title, dates, highlights). Work under NDA appears only here, never as a Project.
_Avoid_: Job, work history, position

**Resume**:
Alan's career summary, published both as a web page and as a downloadable PDF generated from the same source. The public Resume omits phone numbers and references.
_Avoid_: CV
